# GAN Image Quality and Diversity Analyzer

Evaluates images generated by a GAN without training a GAN from scratch.
It checks how many images are unique, how similar they are to each other,
visualizes the diversity of the samples, and reports whether the set looks
diverse or repetitive (mode collapse).

The project has two versions:

| Version | Folder / file | Tech | Use it for |
|---|---|---|---|
| Streamlit app | `app.py` | Python, Streamlit, NumPy, Pillow, PyTorch | Main assignment version, includes a real pretrained DCGAN |
| Web app | `web/index.html` | HTML, CSS, JavaScript (Canvas) | Live demo deployed on Vercel |

## Features (both versions)

1. **Load images**: pretrained GAN / sample generator, or upload your own generated images (images or .zip)
2. **Gallery** of all generated images
3. **Uniqueness**: perceptual hashing (64-bit average hash) groups near-duplicate images
4. **Similarity**: cosine similarity between every pair of images
5. **Diversity visualization**: similarity heatmap, 2D PCA plot, similarity histogram
6. **Report**: verdict (Diverse / Moderately diverse / Repetitive) with a downloadable report

## How the analysis works

- **Average hash**: each image is shrunk to 8x8 greyscale; every pixel becomes 1 if it is
  brighter than the mean, else 0. Two images whose hashes differ by only a few bits are duplicates.
- **Cosine similarity**: each image becomes a 32x32 RGB vector (centred and normalised);
  the dot product of two vectors is their similarity (1 = identical, 0 = unrelated).
- **PCA**: the vectors are projected to 2D. Points spread out = diverse, tight clusters = repetitive.
- **Verdict**:
  - Diverse: unique ratio ≥ 90% and average similarity < 0.6
  - Repetitive: unique ratio < 70% or average similarity ≥ 0.8
  - Moderately diverse: everything in between
- **Diversity score** = (1 − average similarity) × unique ratio

## Run the Streamlit app

```bash
pip install -r requirements.txt
streamlit run app.py
```

On macOS you can instead run: `bash Run_GAN_Analyzer.command`

## Run the web app

Open `web/index.html` in any browser. No installation needed.

## Deploy the web app on Vercel

1. Push this repository to GitHub.
2. On vercel.com: **Add New → Project → Import** this repo.
3. Set **Root Directory** to `web` and **Framework Preset** to `Other`.
4. Click **Deploy**.

(The Streamlit app can't run on Vercel because it needs a long-running Python server.
It can be deployed free on Streamlit Community Cloud instead.)
